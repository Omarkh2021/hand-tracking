# hand-tracking

## Hand Tracking and Finger Counting using OpenCV and MediaPipe

### Overview
This project demonstrates real-time hand tracking and finger counting using Python, OpenCV, and Google's MediaPipe library. By detecting hand landmarks and analyzing their positions, we can accurately count the number of raised fingers.

### Features
- **Hand Landmarks Detection**: Identify 21 keypoint locations on the hand.
- **Finger Counting**: Determine how many fingers are raised.
- **Real-Time Visualization**: Display hand landmarks and finger count in a video stream.

### Prerequisites
Make sure you have the following installed:
- Python 3.x
- OpenCV
- MediaPipe

### Installation
1. Clone this repository:
   ```
   git clone https://github.com/your-username/hand-tracking.git
   cd hand-tracking
   ```

2. Install dependencies:
   ```
   pip install opencv-python mediapipe
   ```

### Usage
1. Run the hand tracking script:
   ```
   python hand_tracking.py
   ```
